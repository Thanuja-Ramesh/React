Day 1: React Fundamentals & Core Notes

1. What is React?

React is an open-source JavaScript library used to build interactive and reusable user interfaces, especially for single-page web applications. React was created at Facebook and open-sourced in 2013. Maintained by Meta and a vast open-source community, React focuses directly on the View layer of an application.

2. Is React a Library or a Framework?

React is a library, not a framework. It is unopinionated and focused exclusively on the view layer. Unlike frameworks (like Angular), React does not enforce routing, state management, or HTTP clients out of the box, allowing developers the freedom to assemble their preferred ecosystem.

3. What is a Component?

A component is an independent, reusable piece of UI. In modern React, components are JavaScript functions that accept inputs (props) and return JSX elements describing what should appear on screen.

4. Why are Components Important?

  • Reusability: Write once, render anywhere across your application.
  • Maintainability & Readability: Code is separated into clean, modular units rather than one giant monolithic file.
  • Separation of Concerns: Each component manages its own structure, style, and behavior.
  • Testability: Isolated components can be unit-tested efficiently.

5. What is JSX (JavaScript XML)?

JSX is a syntax extension for JavaScript that looks similar to HTML. It enables developers to write UI markup directly within JavaScript files. Build tools like Vite convert JSX into valid browser-executable JavaScript.

const App = () => { return ( <div className="card"> <h1>Hello React!</h1> </div> ); };

6. Real DOM vs. Virtual DOM & Reconciliation

Real DOM: The tree representation of HTML elements in the browser. Direct manipulations can be slow and computationally expensive.

Virtual DOM: A lightweight in-memory representation of the Real DOM kept in memory.

Reconciliation: The process where React compares the new Virtual DOM tree against the previous one (diffing algorithm), determines minimal updates, and efficiently applies changes to the browser DOM.
