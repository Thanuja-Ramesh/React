Day 01: React Fundamentals & Core Architecture Guide

1. What is React?

React is an open-source JavaScript library developed by Facebook (Meta) in 2013 for building high-performance, interactive, and modular user interfaces. It focuses directly on the View layer of the MVC pattern and uses a declarative programming model.

Instead of manually manipulating DOM nodes via document.getElementById, developers describe what the UI should look like for a given state, and React handles the DOM rendering automatically.

2. Is React a Library or a Framework?

React is strictly a library, not a full framework. It is unopinionated about routing, data fetching, build tools, or styling. Developers are empowered to integrate ecosystem tools (such as React Router, Vite, Axios, Tailwind CSS) based on project requirements.

3. What is a Component & Why are they Essential?

A component is a self-contained, reusable building block of a user interface. In modern React, components are JavaScript functions that accept props and return JSX.

  • Reusability: Write a component once (e.g., Button, Navbar) and render it anywhere.
  • Maintainability: Eliminates monolithic multi-thousand-line HTML files.
  • Separation of Concerns: Each component manages its own structure, style, and state logic.
  • Testability: Independent units are easy to verify with unit testing tools.

4. JSX (JavaScript XML) & Compilation

JSX is a syntax extension allowing HTML-like tags inside JavaScript. Compilers (such as Babel, ESBuild, or Rolldown via Vite) transform JSX into standard JavaScript function calls (React.createElement or the JSX transform).

// JSX Syntax const App = () => { return ( <div className="container"> <h1>Hello React 19!</h1> <p>Declarative UI in action.</p> </div> ); };

5. Virtual DOM, Real DOM & Reconciliation

Real DOM: The browser's tree representation of HTML nodes. Direct updates cause expensive browser recalculations (reflow and repaint).

Virtual DOM: A lightweight in-memory representation of the Real DOM kept synchronized in memory.

Reconciliation: When state changes, React produces a new Virtual DOM tree, runs an efficient diffing algorithm against the previous snapshot, calculates the minimal changeset, and batch-updates the Real DOM.
